# Move It – Hosted on GitHub Pages

A responsive, single-page website for a fictional moving company.  
Built with **HTML**, **CSS**, **Bootstrap**, and hosted directly on **GitHub Pages**.  
This project focuses on showcasing a clean, mobile-friendly design with smooth scrolling navigation and modern UI components.

## Features

- **Responsive layout** – Works seamlessly on desktop, tablet, and mobile devices.
- **Smooth scrolling navigation** between page sections.
- **Bootstrap components** such as navbar, buttons, cards, and forms.
- **Call-to-action section** to engage visitors.
- **Contact form** (static form layout – no backend).
- **Fast and lightweight** – optimized for quick load times.
- Hosted for free using **GitHub Pages**.

---

## Technologies Used

- **HTML5** – structure and content
- **CSS3** – custom styling
- **Bootstrap 5** – responsive grid system & UI components
- **JavaScript** – smooth scrolling and interactive elements
- **GitHub Pages** – static hosting
